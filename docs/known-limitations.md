# القيود والمجهولات المعروفة

تُحدَّث هذه القائمة مع نتائج التحقق. لا تحوّل الملاحظات إلى ادعاءات مؤكدة دون دليل.

## قيود مثبتة حالياً
1. **لا يوجد lockfile في المستودع عند مراجعة 2026-10-31.** سير CI يستخدم npm install عند غياب package-lock.json، لذا قد تختلف شجرة الاعتماديات بين تشغيل وآخر. يلزم إنشاء lockfile واختباره لاعتماد تثبيت قابل لإعادة الإنتاج.
2. **لا توجد اختبارات E2E أو اختبارات متصفح ظاهرة.** Vitest يستهدف tests/**/*.test.ts ببيئة Node وفق vitest.config.ts؛ وهذا لا يغطي تفاعلات السحب واللمس أو PWA على أجهزة فعلية.
3. **فحص lint محدد للمجلد src** عبر oxlint src، ولا يشمل تلقائياً الاختبارات والسكريبتات وملفات الإعداد.
4. **الإشعارات مقيدة بالمنصة والمتصفح.** README يوثق قيود iOS Safari وسلوك throttling في التبويب الخلفي؛ لا تعد المستخدم بوصول مضمون.
5. **توليد أيقونات PNG يحتاج ImageMagick**؛ GitHub Actions يثبته قبل تشغيل السكريبت.
6. **لم تُنفذ معاينة بصرية في هذا الفحص** لأحجام الشاشات أو السحب أو قارئات الشاشة؛ لا تدّع اكتمال التحقق البصري.

## ملاحظات CI مثبتة

- workflow يستخدم Node.js 22 وnpm. لا تغيّره لمجرد أن قالب Nawy للمشاريع الجديدة يستخدم baseline مختلفاً؛ افحص التوافق في تغيير مستقل.
- آخر تشغيل نشر تم فحصه كان run 301 على commit 58e06244edbb98edd054a8d12adf2716a0403bf3 بتاريخ 2026-10-26، ونجح فيه lint والاختبارات والبناء والنشر.
- نجاح CI لا يثبت سلامة كل الوظائف أو الأجهزة.

## مجهولات لا تفترضها

- حالة حماية فرع main ومتطلبات مراجعة الكود لا تزال غير متحققة.
- التغطية الكاملة لحالات المؤقت عند إغلاق المتصفح أو قتل التطبيق غير مثبتة.
- دعم السحب والأداء عبر كل الأجهزة والمتصفحات يحتاج اختباراً يدوياً أو E2E.
