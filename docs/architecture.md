# معمارية ناوي فوكاس — الحالة الفعلية

> هذه الوثيقة تصف ملفات المستودع الحالية ولا تفرض بنية مستقبلية.

## صورة عامة

React + TypeScript مع Vite، وDexie فوق IndexedDB لتخزين جلسات المستخدم محلياً. لا تظهر في الاعتماديات الحالية SDK لحسابات المستخدمين أو مزامنة سحابية.

## نقاط الدخول والطبقات

| المسار | المسؤولية الحالية |
|---|---|
| index.html | مستند التطبيق وبياناته الوصفية |
| src/main.tsx | نقطة دخول React وتهيئة التطبيق |
| src/App.tsx | تركيب الواجهة والحالات الرئيسية |
| src/components/ | مكونات العرض والتفاعل |
| src/hooks/useTimer.ts | دورة حياة المؤقت وربط المنطق بالحالة |
| src/hooks/useStopwatch.ts | دورة حياة ساعة الإيقاف والعرض الحي |
| src/hooks/useSessions.ts | سجل الجلسات والملخصات والاستيراد والتصدير |
| src/lib/timer.ts | آلة حالات المؤقت ودواله النقية |
| src/lib/stopwatch.ts | حساب ساعة الإيقاف واللفات |
| src/lib/backup.ts و csv.ts | النسخة الاحتياطية وCSV |
| src/db.ts | قاعدة Dexie وعمليات الجلسات |
| src/types.ts | أنواع المجال |
| tests/ | اختبارات Vitest |

## تدفق البيانات

1. المكونات تستدعي hooks لإدارة التفاعل وحالة العرض.
2. hooks تستخدم منطق المجال في src/lib/ لتحديث الحالات الزمنية.
3. useSessions يستدعي دوال src/db.ts لقراءة الجلسات وكتابتها وحذفها واستيرادها وتصديرها.
4. src/db.ts يستخدم Dexie للوصول إلى IndexedDB باسم nawy-focus-db.
5. منطق المؤقت والساعة يُختبر منفصلاً في tests/.

## PWA والنشر

- إعداد PWA موجود في vite.config.ts.
- base: './' مقصودة لدعم النشر بمسار فرعي.
- scripts/generate-icons.sh يتطلب ImageMagick لتوليد PNG.
- .github/workflows/deploy.yml يبني المشروع وينشر GitHub Pages عند push إلى main.

## حدود

- أبقِ منطق التوقيت مستقلاً عن مكونات React.
- لا تجعل المكونات تتعامل مباشرة مع IndexedDB.
- لا تغيّر اسم قاعدة البيانات أو schema منشورة دون خطة وموافقة.
- لا تضف خادماً أو Auth أو Sync دون قرار منتج موثق.
- لا تنشئ طبقات إضافية لمجرد اتباع رسم معماري؛ أضفها عندما تحل تعقيداً حقيقياً.
