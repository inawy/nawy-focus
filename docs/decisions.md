# سجل القرارات · Nawy Focus

## 2026-10-14 — اختيار React بدل vanilla DOM

- **القرار:** استخدام React 19 مع Vite.
- **السبب:** واجهة المؤقت وحالاته (idle / running / paused / finished) أنسب لـ component model.
- **البدائل:** vanilla TS مثل nawy-notes. رُفض لسرعة التطوير هنا.

## 2026-10-14 — لا إشعارات ولا خلفية في الـ MVP

- **القرار:** الإشعارات وتشغيل المؤقت في الخلفية خارج النطاق الأساسي.
- **السبب:** سلوك مختلف بين المتصفحات والأجهزة (خاصة iOS).

## 2026-10-14 — Dexie + IndexedDB فقط

- **القرار:** تخزين محلي فقط عبر Dexie؛ لا حساب ولا خادم.

## 2026-10-14 — نسخ احتياطي JSON آمن

- **القرار:** تصدير/استيراد بصيغة `nawy-focus-backup`؛ الاستيراد يضيف الجلسات الجديدة فقط ولا يستبدل الموجودة.
- **السبب:** حماية بيانات المستخدم من الاستيراد الخاطئ؛ متسق مع روح local-first.
