# سجل القرارات · Nawy Focus

## 2026-10-14 — اختيار React بدل vanilla DOM

- **القرار:** استخدام React 19 مع Vite.
- **السبب:** واجهة المؤقت وحالاته (idle / running / paused / finished) أنسب لـ component model؛ الفريق قرر React لهذا المنتج تحديداً.
- **البدائل:** vanilla TS مثل nawy-notes (أبسط حجماً، متسق مع نوت). رُفض لأن سرعة التطوير والتركيب أوضح هنا.
- **التأثير:** حزمة أكبر قليلاً من نوت؛ مقبول مقابل سرعة البناء.

## 2026-10-14 — لا إشعارات ولا خلفية في الـ MVP

- **القرار:** الإشعارات وتشغيل المؤقت في الخلفية خارج النطاق الأساسي.
- **السبب:** سلوك مختلف بين المتصفحات والأجهزة (خاصة iOS).
- **البدائل:** Notification API + service worker. مؤجّل بعد استقرار الـ MVP.

## 2026-10-15 — إشعارات اختيارية + catch-up عند العودة

- **القرار:** Notification API من الواجهة (ليس push من SW) عند انتهاء الجلسة والتبويب مخفي؛ موافقة صريحة عبر زر «إشعار».
- **السبب:** أبسط من push، يعمل على سطح المكتب؛ على iOS غالباً لا يعمل ويُوثَّق ذلك.
- **أيضاً:** `catchUp` بوقت حقيقي عند `visibilitychange` لتعويض throttle على `setInterval`.
- **البدائل:** Web Push + SW — أثقل ولا يبرر لـ MVP محلي.

## 2026-10-14 — Dexie + IndexedDB فقط

- **القرار:** تخزين محلي فقط عبر Dexie؛ لا حساب ولا خادم.
- **السبب:** اتساق مع عائلة ناوي (local-first).
