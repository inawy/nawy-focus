# ناوي فوكاس · Nawy Focus

تطبيق مؤقت تركيز بسيط **محلي أولاً** (IndexedDB عبر Dexie) يُثبَّت كـ PWA ويعمل بدون إنترنت.

جزء من منظومة [ناوي](https://github.com/inawy) للإنتاجية.

- مؤقت مرن لجلسات التركيز والراحة + مدة مخصصة
- نية اختيارية مع اقتراحات من السجل
- راحة تلقائية اختيارية بعد التركيز
- سجل محلي: فلتر يوم/أسبوع/نوع، حذف، تصدير JSON/CSV
- صوت واهتزاز وإشعار اختياري عند الانتهاء في الخلفية
- عربي أولاً (RTL)، وضع داكن، PWA قابل للتثبيت

الرابط المقترح: [nawy.to/focus](https://nawy.to/focus)

### ملاحظات عن الإشعارات والخلفية

- الإشعار يظهر فقط إذا فعّلته من الزر ووافقت المتصفح، وفقط عندما يكون التبويب في الخلفية.
- على **iOS Safari** غالباً لا تصل إشعارات الويب بالطريقة المتوقعة — هذا قيد منصة وليس عطلاً في التطبيق.
- المتصفحات تبطّئ المؤقت في الخلفية؛ عند العودة يُعوَّض الوقت بـ wall-clock قدر الإمكان.

### التحديث والكاش (PWA)

- بعد كل نشر جديد يُفعَّل Service Worker محدّث تلقائياً ويُعاد تحميل الصفحة عند الحاجة — بدون مسح كاش يدوي في الوضع الطبيعي.
- يُفحص وجود تحديث عند فتح التبويب وكل ساعة تقريباً أثناء بقاء التطبيق مفتوحاً.
- إذا بقيت نسخة قديمة نادراً: أغلق كل نوافذ التطبيق ثم افتحه من جديد، أو من أدوات المطوّر → Application → Service Workers → Unregister.

## النشر على GitHub Pages

1. افتح **Settings → Pages** واختر **Source: GitHub Actions**.
2. أي push على الفرع main ينشر تلقائياً عبر .github/workflows/deploy.yml.

base: './' في vite.config.ts يجعل البناء يعمل على مسار فرعي ونطاق مخصص.

## المبادئ

- المؤقت هو البطل — ليس لوحة إحصائيات
- الإشعارات اختيارية وموافقة صريحة فقط
- لا تعدّل version(n) قديمة في Dexie؛ أضف version(n+1)
- كل اعتمادية جديدة تُسجَّل في docs/decisions.md
